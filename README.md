# tinyServe

A tiny model-serving library.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Layout

```
src/          # library source
benchmarks/   # throughput / latency benchmarks
tests/        # unit and integration tests
```
